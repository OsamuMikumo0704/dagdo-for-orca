# Changelog

## 0.19.0

First source release of this independently maintained fork.

- Local browser task maps and a structured CLI with matching task/workspace operations.
- Projects, Backlog, progress, notes, dependency validation and live updates.
- Shared Undo/Redo for map changes and optional Orca workspace integration.
- Portable startup, locked backups and guarded restore for Windows, macOS and Linux.
- Source ZIP support and setup guides in English, Japanese, Simplified Chinese and Spanish.
- Cross-platform CI, secret scanning, dependency updates and community contribution guides.

Core use requires Bun 1.4.4 or newer. The UI is English. There are no desktop
installers or npm publication for this fork. Task data remains local and backups
are unencrypted JSON. See the README for installation and update instructions.
